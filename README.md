# Demon X AI

Demon X AI is a starter web app project.

## Files
- `index.html` — the web page
- `server.js` — a small Express server
- `package.json` — project scripts and dependencies

## Run locally
1. Install Node.js.
2. In this folder, run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000`.

The current Generate button is only a demo interface. Real AI app generation still needs an AI model/API to be connected.
